**Professional Portfolio**

This repository contains my personal portfolio website, built to showcase my background, technical skills, academic projects, and career goals as a Software Engineering student.

The portfolio is designed with a clean, responsive, and modern interface to provide visitors with a simple way to learn about me, explore my projects, and get in touch.

It includes my professional profile, technical skills, education, selected projects, achievements, resume, and contact information in one place.

The website is built using modern web technologies, including React, Vite, Tailwind CSS, and JavaScript, with a focus on performance, responsiveness, and user experience.

Features
Responsive design for desktop, tablet, and mobile devices.
Professional introduction and About Me section.
Technical skills and technology stack.
Education and academic background.
Featured projects with descriptions.
Resume download option.
Contact section with social media links.
Modern UI with smooth user experience.
